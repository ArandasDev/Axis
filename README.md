# Axis

Aplicativo desktop em Rust para configurar, corrigir e gerenciar controles de videogame
(DualShock 4, DualSense e Xbox) no Windows.

Foco: plug and play, memória por controle (cada controle lembra seu dono e seus ajustes),
transparência total do que foi configurado, kit de correção (drift, calibração, gatilhos)
e baixo consumo de recursos.

> Status: em fase de design. Nenhuma funcionalidade implementada ainda.
